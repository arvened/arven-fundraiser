## 🎯 Что такое FUNDRAISER?

FUNDRAISER — AI-агент для привлечения инвестиций, грантов и спонсорства для стартапов и компаний.

**Четыре режима:**
- 📱 **Консультант** (Бесплатно) — советы по фандрайзингу в Claude.ai
- 📊 **Pitch Deck** (Платно $500–1000) — создание инвестиционной колоды
- 🔍 **Grant Research** (Платно €50–200) — поиск грантов и программ финансирования
- 🤝 **Investor Matching** (Платно €200–500) — подбор инвесторов под твой стартап
